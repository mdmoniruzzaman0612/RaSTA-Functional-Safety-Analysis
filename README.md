# Safety Analysis of the Rail Safe Transport Application (RaSTA)

## Design and Analysis of Mission-Critical Systems

A Functional Safety and RAMS assessment of the Rail Safe Transport Application (RaSTA) protocol for safety-related railway communication systems.

---

## Project Overview

Modern railway systems increasingly rely on distributed communication architectures where safety-related information is exchanged between geographically separated subsystems.

This project investigates the Rail Safe Transport Application (RaSTA), a safety-related communication protocol designed to provide safe communication over non-safe communication networks through the implementation of the Black Channel Principle.

The project applies Functional Safety and RAMS methodologies to analyse communication hazards, derive safety functions, evaluate system reliability, and develop a structured Safety Case.

---

## Standards Applied

* IEC 61508 – Functional Safety
* EN 50126 – Railway RAMS Lifecycle
* EN 50129 – Safety-Related Railway Systems
* EN 50159 – Safety-Related Communication Systems
* DIN VDE V 0831-200 – Rail Safe Transport Application (RaSTA)

---

## Project Objectives

* Identify communication hazards
* Perform risk assessment
* Derive safety requirements
* Analyse the RaSTA architecture
* Evaluate reliability and availability
* Perform Fault Tree Analysis (FTA)
* Develop a Safety Case
* Demonstrate compliance with Functional Safety principles
